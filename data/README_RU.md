# Русский словарь

[English version](README.md).

В `dicts_ru/` находится скомпилированный морфологический словарь русского языка из [mawo-pymorphy3](https://github.com/mawo-ru/mawo-pymorphy3/tree/f60ff89ced0aab256470061e1e566fab317b6170/mawo_pymorphy3/dicts_ru), коммит `f60ff89ced0aab256470061e1e566fab317b6170`. Все 10 файлов сохранены без изменений.

Источник словаря: [OpenCorpora](https://opencorpora.org/), работа участников проекта OpenCorpora. Источник поставки: проект mawo-pymorphy3 команды MAWO. Согласно `dicts_ru/meta.json`, ревизия исходного словаря составляет `417260`, формат скомпилированных данных `2.4`, время компиляции `2025-09-15T06:52:07.147219`.

Набор содержит DAWG слов и суффиксных предсказаний, парадигмы, суффиксы, грамматические таблицы и метаданные. XML OpenCorpora служит входом для компиляции словаря; для чтения готовых файлов он не требуется и в этот набор не включен.

В будущем я, возможно, реализую собственный компилятор словаря для прямой обработки XML OpenCorpora, без использования готовых словарей из mawo-pymorphy3. Пока всё остаётся как есть.
